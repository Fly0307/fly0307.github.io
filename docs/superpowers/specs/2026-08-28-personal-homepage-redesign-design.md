# UnlearnedMan 个人主页重构设计

## 目标

将当前由旧 Hexo 博客生成的静态归档重构为 `UnlearnedMan` 的轻量中英双语个人主页。新站点突出上海交通大学教育经历与 MobiAgent、Penglai 两个代表项目，同时彻底移除原作者文章、身份信息、评论配置、统计代码和旧站链接。

站点继续通过 `Fly0307/fly0307.github.io` 仓库的 `main` 分支根目录发布，不引入新的构建工具或服务端依赖。

## 信息架构

主页采用单页结构，按以下顺序组织内容：

1. 顶部导航：品牌名 `UnlearnedMan`、页面区块链接、中文/English 切换。
2. 首屏介绍：昵称、简短定位、上海交通大学教育背景、主要行动按钮。
3. 代表项目：MobiAgent 与 Penglai 两张项目卡片。
4. 教育经历：上海交通大学本科和硕士经历。
5. 联系方式：GitHub 与 `fly0307@sjtu.edu.cn`。
6. 页脚：昵称、当前年份和简短说明。

另提供独立的 404 页面，引导访客返回主页。

## 文案与链接

页面同时提供中文和英文文案，通过语言切换按钮选择显示语言。初始语言优先参考浏览器语言，用户手动选择后在当前浏览器中保存偏好。

公开信息限制为用户已确认的内容：

- 昵称：`UnlearnedMan`
- 教育背景：上海交通大学本科与硕士
- 邮箱：`fly0307@sjtu.edu.cn`
- GitHub：<https://github.com/Fly0307>
- MobiAgent：<https://github.com/Fly0307/MobiAgent>
- Penglai：<https://penglai-enclave.systems/>

项目说明只使用公开仓库或官方主页能够支持的概括：MobiAgent 聚焦移动设备智能 GUI Agent；Penglai 是面向 RISC-V 的开源、可扩展可信执行环境系统。不虚构职位、论文、时间线或个人贡献范围。

## 视觉设计

整体采用深色、克制的科研与工程风格。用户提供的 16:9 航天图片作为首屏主视觉和个人视觉标识，以宽幅方式展示，避免裁剪成难以辨认的小圆形头像。

视觉原则：

- 深蓝黑背景搭配低饱和红色或暖白色强调色，与航天图片协调。
- 通过清晰字号、留白和卡片层次建立阅读节奏。
- 不依赖外部字体、图标库或 CDN；图标使用内联 SVG 或文字标签。
- 桌面端突出宽幅主视觉，移动端调整为纵向布局并保留图片主体。
- 动画仅用于轻微入场和交互反馈；遵循 `prefers-reduced-motion`。

## 技术结构

新站点保持为直接可发布的静态文件：

- `index.html`：语义化主页结构及中英双语内容。
- `css/site.css`：响应式布局、主题、语言显示状态和可访问性样式。
- `js/site.js`：语言切换、偏好保存和当前年份更新。
- `404.html`：中英双语错误页。
- `img/hero-space.png`：用户提供的主页主视觉图片。
- `.nojekyll`：明确禁用 Jekyll 处理，按原样发布静态文件。
- `README.md`：说明站点内容、维护方式和部署方式。

不引入 `package.json`、Hexo、Jekyll、自定义 GitHub Actions 或其他构建步骤。推送到 `main` 后沿用现有 GitHub Pages 分支发布配置。

## 清理范围

以下旧站内容将从当前版本删除：

- `2020/`、`2021/`、`2022/` 全部旧文章。
- `archives/`、`categories/`、`tags/`、`page/`、`links/`、旧 `about/`。
- 旧 Fluid 主题的 CSS、JavaScript、搜索索引、提示库和图片素材。
- Jekyll 示例 `_config.yml`、`index.md`。
- Gitalk OAuth 配置、`Dunky-Z/comment`、百度统计 ID、`Dominic` 作者信息及旧主页链接。

Git 历史不会在本次重构中重写。若旧 Gitalk OAuth Secret 仍然有效，仍需由对应 OAuth App 所有者撤销或轮换；从当前版本删除并不能清除历史提交中的凭据。

## 可访问性与安全

- 使用语义化标题、导航、主内容和页脚。
- 所有交互元素支持键盘操作并有清晰焦点状态。
- 航天图片提供中英文可理解的替代文本。
- 颜色对比满足正文阅读需要。
- 外部链接使用安全的 `rel="noreferrer"` 配置。
- 邮箱使用标准 `mailto:` 链接，不加入第三方表单或跟踪脚本。
- 不保留评论系统、分析脚本、OAuth 凭据或远程执行代码。

## 验证标准

1. 本地静态服务器访问主页和 404 页面均成功。
2. 中文与英文切换正确，刷新后保留用户选择。
3. GitHub、邮箱、MobiAgent 和 Penglai 链接均指向确认地址。
4. 桌面和移动视口无水平溢出，导航与内容可正常阅读。
5. 键盘可以访问所有按钮和链接，减少动画设置生效。
6. 仓库当前版本不再包含旧文章目录、旧作者标识、Gitalk Secret、百度统计 ID 或 `Dunky-Z/comment`。
7. 站点无需构建即可由 GitHub Pages 从 `main` 根目录发布。

## 非目标

- 本次不恢复博客写作、文章分类、搜索或评论功能。
- 不添加后台、数据库、访问统计或联系表单。
- 不声明未经用户确认的真实姓名、研究职位、论文或项目贡献。
- 不重写 Git 历史，也不自动推送或修改 GitHub Pages 设置。
