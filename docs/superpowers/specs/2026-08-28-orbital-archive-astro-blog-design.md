# UnlearnedMan「轨道档案」主页与博客设计

## 背景

当前仓库已经从 Dominic 的旧博客归档重构为 UnlearnedMan 的中英双语静态个人主页，并完成了旧文章、旧作者资料、旧主页链接和 `Dunky-Z/comment` Gitalk 配置的清理。现有页面能够直接由 GitHub Pages 发布，但内容层次较少，也没有可持续维护的博客写作流程。

本次改造将现有纯 HTML 主页迁移到 Astro 静态站点，采用「轨道档案 / Orbital Archive」视觉方向，增加研究与项目叙事、滚动动效和 Markdown 博客。构建结果仍为静态 HTML、CSS 与 JavaScript，由 GitHub Actions 发布到 `https://fly0307.github.io/`。

## 目标

1. 将主页扩展为具有深空、轨道和任务档案视觉语言的个人研究主页。
2. 通过分层星空、轨道进度和章节进入动画增强浏览叙事，但不牺牲阅读、性能或可访问性。
3. 使用 Astro 内容集合管理 Markdown 博客，并在构建时校验文章元数据。
4. 保持站点界面中英双语；每篇博客只保留其原始语言，不强制翻译。
5. 通过 GitHub Actions 自动检查、构建并部署 GitHub Pages。
6. 继续确保仓库当前版本不包含旧作者文章、身份、链接、评论仓库或 OAuth 配置。

## 技术选择

采用 Astro，而不是继续维护纯 HTML、迁移到 Eleventy 或恢复 Jekyll。

Astro 的内容集合适合校验 Markdown 元数据并生成博客路由；组件与布局能力足以组织复杂首页，同时默认生成静态页面。与 Eleventy 相比，Astro 对内容模型与页面组件的边界更清晰；与 Jekyll 相比，不受 GitHub Pages 安全模式和插件白名单约束。部署仍使用 GitHub Pages 官方 Actions，不引入服务端运行时、数据库或第三方内容平台。

## 信息架构

### 全站导航

全站导航包含以下入口：

- 主页 / Home
- 项目 / Projects
- 博客 / Blog
- 关于 / About
- 中文 / English 界面切换

首页中的项目、关于等入口可以定位到页面章节；博客入口进入独立归档页。导航在滚动后收缩为半透明任务栏，但不遮挡正文。

### 首页

首页按以下顺序组织：

1. **首屏 / Launch**：使用用户提供的火箭图片作为宽幅主视觉，展示 UnlearnedMan、上海交通大学本科与硕士背景、简短研究定位，以及项目和博客入口。
2. **研究轨道 / Research Orbit**：以少量轨道节点表达当前研究兴趣。只使用用户确认或公开项目能够支持的概括，不虚构职位、论文、时间线或贡献范围。
3. **项目任务 / Missions**：重点展示 MobiAgent 与 Penglai。MobiAgent 链接至 `https://github.com/Fly0307/MobiAgent`，Penglai 链接至 `https://penglai-enclave.systems/`。
4. **最新日志 / Transmissions**：展示最近三篇已发布文章；没有文章时显示双语空状态，不生成虚构技术文章。
5. **关于 / Profile**：作为 `#about` 导航目标，组合教育经历与联系方式；展示上海交通大学本科与硕士经历、`fly0307@sjtu.edu.cn`、`https://github.com/Fly0307` 和相关项目链接，不添加未经确认的年份、院系或学位状态。

### 博客归档页

`/blog/` 展示所有非草稿文章，默认按发布日期倒序排列。列表卡片包含标题、摘要、发布日期、文章语言、标签和预计阅读时间。

归档页支持按语言、标签和年份筛选。筛选在浏览器端完成，并同步到查询参数，使筛选结果可以刷新和分享。JavaScript 不可用时仍显示完整文章列表。

### 文章页

文章地址为 `/blog/<slug>/`，其中 `slug` 默认取自 Markdown 文件名。文章页包含标题、摘要、发布日期、更新日期、语言、标签、阅读时间、正文目录、上一篇/下一篇和返回归档入口。

文章页保留静态星空、坐标刻度和轻量进入动画，但关闭首页的持续视差与高密度粒子，优先保证长文阅读。代码块提供语法高亮与横向滚动，不强制加载客户端代码高亮器。

### 其他输出

- `/404.html`：中英双语错误页。
- `/rss.xml`：一个包含全部已发布文章的 RSS，条目保留各自语言。
- `/sitemap-index.xml`：站点地图索引。

## 视觉系统

### 视觉语言

「轨道档案」采用深空黑、冷蓝和星光白作为主色，少量琥珀色用于状态、日期或关键行动提示。界面使用细轨道线、坐标刻度、任务编号、状态标签和等宽字体形成科研档案感，同时通过较大的标题和充足留白避免成为密集 HUD。

用户提供的 `img/hero-space.png` 继续作为主页核心视觉，不裁剪为传统圆形头像。迁移后图片放入 Astro 的公共资源目录，并通过响应式容器、渐变遮罩和明确替代文本保持主体可见。

不依赖外部字体、图标库或视觉 CDN。图标使用文字、CSS 或内联 SVG，避免第三方资源失败影响页面。

### 响应式布局

- 宽屏首屏使用不对称双栏或叠层构图，文字与火箭主体保持独立视觉焦点。
- 中等屏幕降低轨道装饰密度，项目区域改为两列或单列。
- 移动端使用纵向内容流，保留图片主体，缩减轨道线、粒子数量和视差幅度。
- 页面在常见移动与桌面宽度下不产生横向溢出。

## 动效系统

动效是渐进增强层，不承担内容可见性或导航功能。

1. **星空层**：Canvas 绘制低密度星点；首屏可见时运行，离开视口后暂停。移动端减少粒子数量。
2. **首屏视差**：图片、星层和文字以不同但克制的速度移动，形成从发射场进入轨道的感觉。
3. **轨道进度**：桌面端侧边进度轨道随滚动点亮当前章节；移动端降级为顶部细进度线。
4. **章节显现**：使用 `IntersectionObserver` 添加进入状态，标题、轨道线和卡片按短间隔依次出现。
5. **项目节点**：项目卡片悬停或聚焦时强化轨道节点、任务状态和外链提示。
6. **博客信号**：最新文章的日期、语言与标签使用一次性短动画显现，不持续闪烁。

连续动画统一通过一个受控的 `requestAnimationFrame` 循环驱动，并在页面不可见、Canvas 离开视口或用户要求减少动态效果时停止。`prefers-reduced-motion: reduce` 下关闭粒子运动、视差、轨道延伸和连续过渡，仅保留即时状态变化。

不引入 Three.js 或其他 3D 引擎。本期不制作 WebGL 场景、鼠标跟随相机或全屏滚动劫持。

## Astro 架构与组件边界

### 页面与布局

- `src/pages/index.astro`：组合首页各章节，不承载底层动画实现。
- `src/pages/blog/index.astro`：查询、排序并输出博客归档数据。
- `src/pages/blog/[...slug].astro`：为每篇已发布文章生成静态路由。
- `src/pages/404.astro`：错误页。
- `src/layouts/BaseLayout.astro`：全站元数据、导航、页脚、语言初始化和公共样式入口。
- `src/layouts/PostLayout.astro`：文章头部、目录、正文、上一篇/下一篇与文章级元数据。

### 内容组件

- `Hero`：首屏文案、主视觉和行动入口。
- `ResearchOrbit`：研究方向节点。
- `ProjectMissions`：MobiAgent 与 Penglai 项目卡片。
- `LatestTransmissions`：最新文章或空状态。
- `EducationTrajectory`：教育经历。
- `ContactPanel`：邮箱与外部链接。
- `PostCard`、`PostMeta`、`TagList`：在首页、归档和文章页复用统一博客展示。
- `LanguageToggle`：切换站点界面语言，不翻译文章正文。

组件只接收展示所需数据，不在内部重复查询内容集合。页面负责查询和排序，组件负责语义化输出。动画脚本通过 `data-*` 钩子增强服务端生成的 HTML，不要求将整个页面转为客户端应用。

### 动效模块

- 星空模块只管理 Canvas 生命周期和绘制。
- 章节观察模块只管理进入视口状态。
- 滚动进度模块只读取章节位置并更新当前章节。
- 语言模块只管理界面语言、`lang` 属性、替代文本与本地偏好。

这些模块相互独立；任何一个模块失败都不会隐藏正文或阻止链接工作。

## 博客内容模型

文章存放在 `src/content/blog/`，每个 Markdown 文件只使用一种语言。内容集合校验以下字段：

```yaml
title: "文章标题"
description: "用于列表和元数据的摘要"
publishedAt: 2026-08-28
updatedAt: 2026-08-28 # 可选
language: zh             # zh 或 en
tags: ["Security"]      # 可为空数组
draft: false             # 默认 false
featured: true           # 默认 false
```

字段语义：

- `title`、`description`、`publishedAt`、`language` 为必填项。
- `language` 只允许 `zh` 或 `en`，并设置文章页根内容的语言属性。
- `updatedAt` 不得早于 `publishedAt`。
- `draft: true` 的文章在生产构建中不进入首页、归档、RSS、站点地图或文章路由。
- `featured: true` 优先进入首页最新日志；不足三篇时按发布日期补足，仍不展示草稿。
- 标签保留作者输入的显示形式，同时生成稳定、URL 安全的筛选值。

仓库提供一个不发布的 Markdown 模板，说明字段与写作步骤，但不提供虚构的公开文章。

## 中英双语规则

站点界面继续支持中文与英文切换。初始界面语言优先使用已保存偏好，其次参考浏览器语言；浏览器存储不可用时使用浏览器语言并正常显示。

语言切换只影响导航、按钮、章节标题、空状态和系统说明。博客标题、摘要、标签与正文保持文章原始语言，不自动翻译，也不隐藏与当前界面语言不同的文章。归档页的语言筛选是独立内容过滤条件。

每篇文章和包含不同语言内容的卡片使用正确的 `lang` 属性，帮助屏幕阅读器和搜索引擎识别语言。

## 数据流

```text
Markdown 文章
    ↓ Astro 内容集合校验
已发布文章数据
    ├── 首页最新日志
    ├── 博客归档与筛选元数据
    ├── 静态文章路由
    ├── RSS
    └── 站点地图

Astro 页面与组件
    ↓ npm run build
dist/ 静态站点
    ↓ GitHub Pages artifact
https://fly0307.github.io/
```

运行时没有数据库、内容 API 或服务端请求。筛选、语言偏好和动效只处理构建时已经输出的页面内容。

## 错误处理与降级

- 缺失或非法文章字段导致构建失败，并在本地或 Actions 日志中指出具体文件。
- 没有已发布文章时，主页和归档显示双语空状态，构建仍成功。
- 文章卡片始终使用标题、摘要与元数据排版，不要求封面图片，也不请求占位图片。
- JavaScript 被禁用或运行失败时，导航、项目链接、文章列表和正文仍可使用；筛选退化为完整列表。
- `localStorage` 不可用时不报错，语言选择在当前页面仍然生效。
- Canvas 不可用时显示纯 CSS 静态星空背景。
- 外部项目链接失败不影响站点其他内容；外部链接使用安全的 `rel` 属性。
- 404 页面提供返回主页与博客归档的入口。

## GitHub Pages 部署

Astro 配置使用静态输出，`site` 设置为 `https://fly0307.github.io`。这是用户名主页仓库，因此生产路径以 `/` 为根，不添加仓库名称前缀。

`.github/workflows/deploy.yml` 在 `main` 分支推送和手动触发时执行：

1. 检出代码并安装锁定的 Node.js 依赖。
2. 运行 Astro 检查、仓库回归测试和生产构建。
3. 使用 `actions/configure-pages@v5` 配置 Pages。
4. 使用 `actions/upload-pages-artifact@v4` 上传 `dist/`。
5. 由依赖构建任务的部署任务使用 `actions/deploy-pages@v4` 发布。

工作流使用 `contents: read`、`pages: write` 与 `id-token: write` 最小权限，部署环境为 `github-pages`。同一时间只保留最新部署，防止旧构建覆盖新版本。仓库 Pages 来源需设置为 **GitHub Actions**。

构建产物不提交到 `main`，也不维护 `gh-pages` 分支。真正上线只在代码被推送到 GitHub 且 Actions 成功后发生。

## 迁移范围

当前根目录静态页面迁移为 Astro 源码：

- `index.html` 迁移到页面、布局与内容组件。
- `404.html` 迁移到 Astro 404 页面。
- `css/site.css` 拆分为全局设计令牌、布局、组件与文章样式；避免形成单个超大样式文件。
- `js/site.js` 拆分为语言、星空、章节观察和滚动进度模块。
- `img/hero-space.png` 迁移到公共资源目录并保留当前图片内容。
- `.nojekyll` 不再作为根目录直接发布契约；Pages 发布的是 Actions 上传的 `dist/`。
- 新增 `package.json`、锁文件、Astro 配置、内容集合配置和 GitHub Actions 工作流。
- `dist/`、本地缓存和视觉 brainstorming 临时文件保持不跟踪。

现有静态回归测试将更新为检查 Astro 源码与构建产物。迁移不得恢复已经删除的旧文章目录或第三方主题资源。

## 测试与验收

### 自动检查

1. Astro 类型与内容集合检查通过。
2. 生产构建成功并输出主页、404、博客归档、RSS 与站点地图。
3. 语言逻辑测试覆盖已保存偏好、浏览器语言、无存储环境和切换行为。
4. 内容模型测试覆盖有效中英文文章、草稿排除、非法语言和缺失必填字段。
5. 静态回归检查确认姓名、邮箱、GitHub、MobiAgent 与 Penglai 链接正确。
6. 静态回归检查确认当前源码与构建产物不包含 Dominic、旧主页、`Dunky-Z/comment`、旧 Gitalk/OAuth 配置和旧文章路径。
7. 内部链接与关键资源路径在根域部署配置下有效。

### 浏览器验收

1. 中文与英文界面切换正确，刷新后保留选择；博客正文不随界面语言被翻译或隐藏。
2. 桌面、平板与移动视口无水平溢出，导航和博客筛选可用。
3. 键盘可以访问导航、语言切换、筛选、项目卡片和文章链接，焦点状态清晰。
4. 滚动进度、章节显现、首屏视差与星空在正常动态偏好下按设计工作。
5. `prefers-reduced-motion` 下连续动画与视差关闭，内容立即可见。
6. JavaScript 禁用时仍能阅读全部核心内容和文章列表。
7. 文章长标题、长代码行、空标签与没有文章等边界场景不破坏布局。

## 安全与隐私

- 不接入旧 Gitalk 或任何评论系统，不保存 OAuth 客户端信息。
- 不添加访问统计、追踪像素、联系表单后台或第三方脚本。
- 邮箱继续使用标准 `mailto:` 链接。
- 外部链接使用 `rel="noreferrer"`。
- Git 历史不在本次改造中重写；若历史中的旧 OAuth 凭据仍有效，仍需由对应 OAuth App 所有者撤销或轮换。

## 非目标

- 不实现评论、登录、后台编辑器、数据库或全文搜索。
- 不实现文章自动翻译或一篇文章的中英双版本关联。
- 不实现 WebGL、3D 场景、滚动劫持、音效或持续闪烁界面。
- 不新增未经用户确认的姓名、院系、研究职位、论文、经历年份或项目贡献描述。
- 不恢复 Dominic 的任何旧文章、个人信息、链接、主题资产或评论数据。
- 不自动推送代码、不替用户修改 GitHub 仓库设置，也不在本地构建成功前触发线上部署。

## 完成定义

当 Astro 站点在本地通过全部检查与浏览器验收、Markdown 博客流程可用、旧作者内容回归检查通过、GitHub Pages Actions 工作流配置完整，并且仓库中包含清晰的写作与部署说明时，本次实现视为完成。线上发布属于随后经用户授权执行的推送步骤。
